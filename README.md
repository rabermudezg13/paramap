# Miami Schools Map

Static web app for GitHub Pages.

## Features
- Potential Schools vs. Paraprofessional Openings
- Search by neighborhood, ZIP code, or full address
- 5 / 10 / 15 / 25 mile radius
- Select a school and calculate distance from the entered address
- Driving distance and estimated travel time when the routing service is available
- Google Maps directions link
- OpenStreetMap + Leaflet
- Browser caching for geocoded school locations

## GitHub Pages
Publish from the `main` branch and `/ (root)` folder in **Settings > Pages**.
